# Editor

Editor gives Craft plugins and modules a front-end rich-text editor, along with the server code that sanitises and renders what people write.

Editor is a toolkit for developers. If your plugin or site module lets people write something on the front end, such as a comment, a reply, a forum post or a message, Editor provides the editor they write in and checks everything it sends. It covers formatting, Markdown shortcuts, links to any address or to pages on your site, mentions, photo and file uploads, character limits, saved drafts and post errors. Your code still decides who may post, where the document is stored and who gets notified.

Site owners don't install Editor themselves. It arrives as a dependency of a plugin that uses it, or of a module in their own project.
