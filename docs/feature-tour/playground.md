# Playground

This is the editor, `<verbb-editor>`, running live. Pick a setup to see its range, from a compact box where Enter sends to a full toolbar for longer writing, and a header that switches between modes. Then change the look, add files, or make things go wrong to see how the editor handles it.

<EditorPlayground />

There's no Craft site behind this page. People and pages come from a small sample list, and uploads stay in your browser. Nothing you post goes anywhere. In your own plugin the same editor talks to Editor's Craft endpoints, as [Craft Integration](../developers/craft-integration.md) describes.

The rest of the Feature Tour takes each part in turn, starting with the toolbar and Markdown shortcuts in [Writing & Formatting](writing-formatting.md).
